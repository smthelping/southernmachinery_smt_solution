# Southern Machinery — Pre-sales Solution Generator (public build)

公开版：**只包含应用能力与规则**（应用外壳、业务逻辑、提示词模板、脱敏后的产品库）。
不包含任何客户名单、报价数据与历史方案全文（详见公司内部库根 `AGENTS.md` §12）。

## 这是什么

把「客户询盘邮件」变成「针对性、可编辑的单 HTML 解决方案文档」的浏览器端工具，面向
SMT / THT 自动插件设备的海外销售场景。

七步流程：询盘解析 → 前置条件清单 → 客户背景调查 → 产品匹配 → 方案生成（含校验）→ 知识库 → 设置。

## 三大设计约束

1. **型号白名单** —— 方案中出现的机型必须存在于产品库，AI 编造的型号会被自动剔除；
2. **数字溯源** —— 正文与表格中的每个数字都必须在「客户输入 / 产品库 / 本地 ROI 测算 / 公司公开资料」中可查出处，
   无法溯源的一律单列为「禁止外发」；
3. **参数不交给模型** —— 关键规格参数由产品库确定性生成，从根上排除参数被改写。

生成采用**分章受控生成**：摘要 → 方案概述 → 规格（产品库直出）→ 供料与 ROI → 服务与后续，
逐章校验、逐章修复，中断后可断点续写。

## 运行

纯静态，无需构建。任意静态服务器即可：

```bash
npx serve .            # 或 python -m http.server 8123
```

> 直接双击 `index.html` 也能用，但浏览器的 `file://` 安全策略会阻止预览区（iframe）渲染。

## 配置 LLM

打开「设置」，填入任意 **OpenAI 兼容**接口（OpenAI / DeepSeek / 自建网关 / 本地 vLLM 等）：

- Base URL 例：`https://api.openai.com/v1`
- API Key 仅保存在**你自己的浏览器** localStorage，不会上传到本仓库或任何第三方
- 未配置也可用：自动降级为规则解析 + 模板方案，全流程可跑通

## 数据边界

- 本仓库**不含**任何客户数据。产品库中的参数来源字段已统一脱敏为
  `Internal solution archive (not public)`。
- 内置语料为空（`data/kb.js` 为占位）。如需使用历史方案做检索，请在「知识库」页导入你自己的文档
  （支持 txt / md / csv / json / pdf），导入内容只保留在你的浏览器中。
- 生成的方案文档保存在本地，本工具不向任何服务器上传内容（除你配置的 LLM 接口）。
